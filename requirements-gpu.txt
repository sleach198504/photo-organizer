# Installed instead of requirements-cpu.txt when an NVIDIA GPU was detected
# and the user chose GPU in the setup prompt. See Setup.bat.
#
# Only the NVIDIA driver is required on the target PC - this wheel bundles
# its own CUDA runtime (cuDNN/cuBLAS/etc via the nvidia-* pip packages), so
# no separate CUDA Toolkit install is needed.
#
# cu126 (CUDA 12.6) is the current well-supported channel as of this writing.
# If a future PyTorch release drops it, bump this to whatever
# https://pytorch.org/get-started/locally/ currently recommends - torch
# always falls back to CPU at runtime (see ClipBackend.device in
# app/content_tagging.py) if the installed build can't actually use the
# GPU, so an outdated channel here degrades gracefully rather than breaking.
--extra-index-url https://download.pytorch.org/whl/cu126
torch>=2.0
